# Local enrollment data (gitignored)

Store FaceNet enrollment JSON and capture photos here:

- `enrollments.json` — generated by `python enroll_identity.py`
- `enroll_photos/<identity>/` — optional captured frames
- `fasnet_calibration/` — labeled FasNet score JSONL from physical REAL/PRINT/SCREEN sessions (no images)
- `identity_calibration/` — labeled FaceNet distance JSONL from physical GENUINE/IMPOSTOR sessions (no images/embeddings; see `../IDENTITY_CALIBRATION.md`)

Do **not** commit embeddings, face photos, calibration JSONL, or copy friend `embeddings_deepface.pkl`.

Threshold `9.0` (euclidean) is an **UNVALIDATED** starting value from the friend's pipeline.

## FasNet backend

Default liveness inference uses DeepFace's official MiniFASNet **ONNX** graphs when
`onnxruntime` is installed (same crops / ensemble math as the TF path; TF remains the
fallback). Force a backend with:

```text
set VIGIL_FASNET_BACKEND=onnx
set VIGIL_FASNET_BACKEND=tf
```

## FaceNet backend

Identity uses the same DeepFace FaceNet-128 weights. When
`data/facenet_onnx/facenet128_deepface_vigil.onnx` exists (export via
`python convert_facenet_to_onnx.py`) and `onnxruntime` is installed, the default
forward path is **ONNX Runtime CPU**; TensorFlow remains the fallback. Preprocess
(opencv extract_faces + align + 160 resize + /255) is unchanged. Force a backend:

```text
set VIGIL_FACENET_BACKEND=onnx
set VIGIL_FACENET_BACKEND=tf
```

Do not commit ONNX exports, `auth_latency_profile*.json`, `facenet_*bench.json`,
or `accel_candidate_bench.json` (local timing / experimental models only).
