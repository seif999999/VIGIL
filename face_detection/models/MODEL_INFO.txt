VIGIL face detector — SCRFD-2.5G_KPS (frozen baseline)

Detection ONNX file used at runtime:
  buffalo_m/buffalo_m/det_2.5g.onnx

InsightFace model-zoo release does not publish a standalone scrfd_2p5gkps.onnx
asset. The buffalo_m pack detection artifact det_2.5g.onnx is SCRFD-2.5G with
five facial keypoints (9 ONNX outputs, use_kps=True), matching SCRFD_2.5G_KPS.
